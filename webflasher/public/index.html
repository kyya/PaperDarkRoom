说明

  • 只有 Chrome / Edge（桌面版，113 以上）支持 WebSerial。Safari、Firefox、以及手机浏览器都刷不了。
  • 用 USB-C 数据线把 M5PaperS3 接到电脑，点上面的「刷入」，在弹出的串口选择框里 选中设备即可。若列表里没有设备，换一根能传数据的线再试。
  • 若初始化失败，按住机身 BOOT 键再点「刷入」，进入下载模式。
  • 首次刷入、或跨大版本升级时，请在弹窗里勾选 Erase device 再点 Next —— nvs 需要清空重新配对，不清会带着旧配置起不来。小版本更新可以不勾。
  • SD 卡存档不受影响。Erase 擦的是板载 flash，游戏存档在 SD 卡上， 怎么刷都还在。
  • 刷完拔线重新上电即可。整包镜像已含 bootloader 与分区表，写入地址固定 0x0。
