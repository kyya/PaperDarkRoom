说明
  • 用 USB-C 数据线把 M5PaperS3 接到电脑，点「刷入」，在弹出的串口选择框里选中设备。
  • M5PaperS3 用的是 ESP32-S3 原生 USB，不需要装 CP210x / CH34x 驱动。 若列表里没有设备，先检查数据线（不能是只能充电的电源线），并确认设备已开机。
  • 若初始化失败，按住机身 BOOT 键再点「刷入」，进入下载模式。
  • 首次刷入、或跨大版本升级时，请在弹窗里勾选「擦除设备」再点下一步 —— nvs 需要清空重新配对，不清会带着旧配置起不来。小版本更新可以不勾。
  • SD 卡存档不受影响。擦除擦的是板载 flash，游戏存档在 SD 卡上， 怎么刷都还在。
  • 刷完拔线重新上电即可。整包镜像已含 bootloader 与分区表，写入地址固定 0x0。
